# ReplayRecoder · 录屏回放

> 做软件测试最烦的一件事：bug 复现了，但没录下来；等你打开录屏，它又不出现了。

这个 App 就是为这个问题做的——**后台一直录，只保留最近 N 分钟，出问题一键定格。**

---

## 它解决什么

- **循环录制**：15 秒分段轮转，只保留最近 N 分钟（30s / 1 / 2 / 5 / 10 / 30 / 60 分钟，7 档）
- **一键定格**：把"最近 N 分钟"冻结成一次事件，App 内回放、写备注、剪辑、导出
- **直接能用**：导出 H.264 MP4，能拖进 Jira / 钉钉 / 微信，不用二次转码
- **两种停法**：定格后 3 秒自动续录（继续蹲守）／彻底停止
- **工具箱**：WiFi / BLE 信号 / 网络诊断 / 噪音计 / 秒表 / 设备信息 / SSH 交互终端

## 技术要点

挑几个真正花时间的地方：

| 问题 | 做法 |
|---|---|
| 不同机型编码器能力不一样，初始化就失败 | 编码器自动降级：100% → 75% → 50% 分辨率与码率重试 |
| 分段录制后合并，时间轴会错位 | 按 PTS 累加合并，处理 extractor 内部指针跨段失效 |
| 剪辑既要快又要兼容 | 优先 FFmpeg 流拷贝（无损、秒级），不支持时回退 libx264 CRF30 |
| 锁屏后还在录，电量和隐私都难受 | 锁屏自动停录并保存，亮屏自动续录 |
| 国产 ROM 杀后台 | 按厂商跳转电池白名单 / 自启动管理，跨厂商保活引导 |
| 悬浮球在部分华为机型黑屏 | 悬浮相机纯预览小窗，规避系统单实例策略 |
