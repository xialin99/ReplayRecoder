# ReplayRecoder 使用指南与解决场景

> 适用版本：App v0.3.0（2026-11-05）｜适用平台：Android 10 及以上（含鸿蒙 4，实测机型华为/荣耀）
> 适用对象：扫地机器人测试（建图 / 清扫 / 避障 / APP 交互回归），其他需要"事后回捞现场"的测试场景同样适用
> 工具定位：循环录屏 + 事件化管理的**测试现场记录仪**

---

## 一、工具是什么

一句话：给测试员配了个**"行车记录仪 + 事件库"**——后台一直在录、只保留最近 N 分钟，出问题一键定格存档，自动带时间水印，可剪辑、可批量分享。

**解决的痛点**：扫地机 bug 往往猝不及防——机器突然卡死、突然重复清扫、建图突然错乱、避障突然失效。等测试员反应过来去开录屏，现场早就过去了。传统两条路都不好走：

| 传统方式 | 问题 |
|---|---|
| 先点开始再操作 | 经常错过首发瞬间 |
| 全程录屏 | 文件动辄几个 G，没人愿意翻 |
| 口述 + 截图 | 说服力弱，开发难复现 |

本工具恰好填补"全程录"与"临时开录"之间的空白：循环缓冲一直在录，任何瞬间都能往回捞；超窗口的旧画面自动删除，磁盘压力小；每次定格都是一条带时间戳的事件，可备注、可检索、可交付。

**技术底座**：Android 原生 MediaProjection 录屏 + Media3/ExoPlayer 回放 + FFmpeg 合并剪辑。数据全部存手机本地（App 私有目录），无云端依赖，符合内网保密要求。

## 二、5 分钟上手

### 2.1 安装

- 分发包可通过钉钉文档下载，或直接 `adb install` 安装到测试机。

### 2.2 首次开录的授权顺序

在主界面点蓝色"开始录制"，按提示依次授权（每项只需一次）：

1. **通知权限**（Android 13+）——前台服务的常驻通知；
2. **悬浮窗权限**——悬浮球和水印靠它显示；
3. **录音权限**——录环境音（选"静音"声源则不需要）；
4. **录屏授权**——系统弹窗，选"整个屏幕"并勾选"不再提示"。

> 首次开录还会弹"后台保活引导"：建议点「加白名单」+「自启动管理」两项都开启，否则国产 ROM 长时间后台录制可能被系统杀掉。

### 2.3 推荐初始配置（扫地机测试场景）

在"设置"里一次性配好：

| 配置项 | 建议值 | 理由 |
|---|---|---|
| 回放窗口 | 5 分钟（默认） | 单个 bug 现场通常几分钟内，5 分钟文件小、翻找快；长流程建图可临时切 30min |
| 时间水印 | 开，位置右下 | 视频自带时刻，开发对齐问题发生时间一目了然 |
| 自定义水印 | 按需，如"扫地机回归" | 标记来源，外发视频更正式 |
| 声音源 | 麦克风 / 混合 | 保留现场异响（电机异响、碰撞声）是重要证据 |
| 画质 | 中（4Mbps） | 清晰度与体积平衡；需看清细小 UI 文案再开高 |

### 2.4 日常就三步

1. **开录**：点蓝色按钮（或悬浮球长按 0.5 秒），之后专心操作机器和被测 APP，不用管它；
2. **定格**：发现问题，长按悬浮球 0.5 秒（或点主界面红色"停止"）——刚才几分钟立即存成一条事件；
3. **交付**：从相册/回放页剪辑、写备注、一键分享。

> 定格后默认 **3 秒自动开始下一段循环录制**，连续复现不用反复开录；想彻底停下来就点红色描边的「彻底停止」。

## 三、核心操作速查

### 3.1 主界面

| 操作 | 效果 |
|---|---|
| 蓝色「开始录制」 | 开始循环录屏 |
| 红色「停止」（实心） | 定格保存事件，约 3 秒后自动续录 |
| 红色「彻底停止」（描边） | 定格保存后不再自动开录 |
| 窗口档位 chips（30s~1h） | 录制中点按即时生效 |
| 最近事件卡 | 直接进最近一条的回放 |

### 3.2 悬浮球手势

| 手势 | 效果 |
|---|---|
| 单击 | 回到 App 主界面 |
| 双击 | 开/关**悬浮相机**小窗（纯预览取景，不拍照不录像） |
| 长按 0.5 秒（不用抬手） | 未录制 → 立即开录；录制中 → 立即停录保存 |
| 拖动 | 移动位置，自动记忆 |
| 颜色 | 蓝色 = 待录；绿色 + 呼吸 = 正在录 |

### 3.3 相机

- **悬浮相机**（双击悬浮球）：悬浮在任意应用之上的实时取景窗，可拖动、缩放，用于"边测边瞄一眼机器状态"。
- **全屏相机**（主界面"相机"按钮）：可拍照、录像，产物自动进事件流统一管理；开启时间水印后成品自动烧录拍摄时刻。**录屏进行中时相机只能拍照、不能录像**（系统限制，避免抢占采集通道）。

### 3.4 停录的四种方式

主界面两个停止按钮 / 长按悬浮球 0.5 秒 / 通知栏"停止"按钮 / 直接锁屏。

> **锁屏保护**：录制中熄屏会自动停录并保存当前事件，亮屏后自动开始新录制——跟机走动、放下手机不会丢现场。

## 四、典型场景与解决路径

### 场景 1：清扫回归中机器突发绕圈 / 卡死（"bug 猝不及防"）

- **做法**：照常测试，发现异常长按悬浮球 0.5 秒 → 最近 5 分钟全程定格。
- **对比**：传统做法截图 + 口述"大概在第 10 分钟"，开发半信半疑；现在机器绕圈的完整轨迹直接在视频里，无争议。

### 场景 2：单次建图超半小时的长流程挂机

- **做法**：开录前把窗口档位调到 30min 或 1h，挂机不干预；超窗口的旧画面自动删除，不会撑爆磁盘。
- **要点**：磁盘占用始终≈一个窗口的量，不用中途清理。

### 场景 3：现场取证——机器外观、碰撞痕迹、地面环境

- **做法**：双击悬浮球呼出悬浮相机先"瞄一眼"；需要留档就从主界面进全屏相机拍照（或录屏停止后录像），照片自动进事件流，与录屏统一管理。

### 场景 4：问题上报开发（只发关键几秒）

- **路径**：相册 → 打开事件 → 剪辑 → 在关键帧时间轴上拖出问题片段（可一键静音）→ 保存为新事件 → 回放页「分享」。
- **要点**：分享自动完成"合并 → 压缩 → 弹出系统分享面板"，钉钉/微信/Jira 任选；**文件名就是备注**（如"清扫建图卡顿#1.mp4"），开发收到即知问题。

### 场景 5：一轮回归发现多个问题，批量交付

- **路径**：相册 → 多选 → 勾选 3 条问题事件 →「分享」→ 一次性多文件发出（钉钉支持）。
- **变体**：多个场景想拼成一条复盘视频 → 多选后「拼接」，自动按时间顺序合成一条新事件。
- **对比**：比发 3 条消息 + 口述清楚得多。

### 场景 6：版本复盘与趋势统计

- **约定备注格式**：`问题现象#轮次#日期`，如 `建图卡顿#清扫第3轮#20260915`。
- **复盘**：相册顶栏搜索"建图卡顿"即可拉出所有同类问题，配合类型筛选（录屏/拍照/录像）做趋势分析，报告有据可查。

### 场景 7：跟机走动、放下手机

- 录制中熄屏 → 自动停录保存；亮屏 → 自动续录。全程无手动操作，不丢现场。

### 场景 8：同一问题需要连续复现多次

- 用红色「停止」（而非「彻底停止」）：每次定格后 3 秒自动开始下一段循环录制，连测连存，最后用「彻底停止」收工。

## 五、与现有测试流程的衔接

| 现有环节 | 衔接方式 |
|---|---|
| 回归前准备 | 设窗口档位（如 5 分钟）、开水印、开循环录屏，完成保活白名单引导 |
| 执行回归 | 专心操作机器/APP，发现问题长按悬浮球定格 |
| 问题复现 | 回放页剪辑关键片段、按规范写备注 |
| 上报开发 | 回放页分享（自动压缩，文件名即备注）；多条问题用相册多选批量分享 |
| 版本复盘 | 相册按备注搜索同类问题，批量拼接做复盘视频，趋势统计 |

**零学习成本**：开始/停止就是主界面按钮，悬浮球长按也能停，不需要培训。
**零额外权限负担**：仅需录屏授权 + 录音 + 通知 + 悬浮窗，**不依赖无障碍辅助功能权限**。
**数据可控**：事件存本地 `filesDir/events/`，不上云；要外发通过"分享"发出（系统分享面板，去向可控）。

## 六、注意事项与边界

1. **平台**：仅 Android 10 及以上，iOS 暂不支持——测试机为 iPhone 需另行评估。
2. **保活**：国产 ROM 后台限制严，务必完成开录时的"电池白名单 + 自启动管理"引导；否则长时间挂机可能被系统杀掉录制。
3. **录屏中相机录像不可用**：系统限制，录屏进行中全屏相机仅可拍照；需要相机视频请先停录或用另一台手机。
4. **外发走"分享"**：分享时视频会自动压缩以兼顾传输；"导出到系统相册"入口已移除，长期留存请把视频分享/转存出去。
5. **事件数据在 App 私有目录**：卸载 App 会一并清除，重要事件及时分享留存。
6. **个人项目属性**：当前为个人开发工具，debug 证书签名，适合内测/试点；试点效果好可评估正式化路径（正式签名、应用市场分发）。
7. **依赖组件**：FFmpeg（合并/剪辑内核，开源、已停止维护但功能稳定）与 Media3 回放，均为成熟开源组件，无商业授权风险。

## 七、常见问题（FAQ）

**Q1：定格后事件什么时候能看到？**
停录后后台要把 15 秒碎段合并成完整视频，约几秒；期间首页/相册显示"生成中"占位卡，完成后自动出现。

**Q2：为什么我的视频只有几秒/时长不对？**
请确认回放窗口档位设置（默认 5 分钟）；刚开录不足一个窗口时，定格只包含已录部分。

**Q3：录制突然停了？**
大概率被系统后台回收：检查电池优化白名单与自启动管理是否都已开启；重新点开始即可，窗口内画面仍在（未定格部分随循环缓存保留最近内容）。

**Q4：分享的视频在对方那里打不开/要下载？**
分享产物为标准 H.264 MP4，主流平台均可在线预览；个别平台对超大文件有限制，可用剪辑功能只发关键片段。

**Q5：悬浮球不见了？**
检查"悬浮球常驻"开关（设置页）与悬浮窗权限；录制中悬浮球必然显示（绿色）。
